# Student Gradebook Project

## Overview

I wanted to learn Java programming to build my skills in multiple languages. This Student Gradebook project helped me understand how to create useful programs that can actually help teachers and students.

I created a gradebook program that lets you add students, record their grades, and calculate averages. The program shows how Java handles storing information, doing calculations, and working with user input. It's like a digital version of a teacher's gradebook that automatically does the math for you.

My goal was to learn how Java works by building something practical. I focused on understanding how to organize code, handle different types of information, and create menus that are easy to use.

[Software Demo Video](https://youtu.be/7SOiiFx-4D0) *Note: You'll need to create and upload your own video*

## Development Environment

I used Visual Studio Code to write the code because it's free and works well for beginners. For running the Java code, I used the Java Development Kit (JDK) that I downloaded from the internet.

The program is written in Java and uses these built-in tools:
- Scanner for getting input from the keyboard
- ArrayList for storing lists of students and grades
- Basic math operations for calculating averages

## How to Use the Program

When you run the program, you'll see a simple menu with four options:

1. **Add Student** - Enter a student's name and ID number
2. **Add Grade** - Record grades for existing students
3. **View Students** - See all students with their grades and averages
4. **Exit** - Close the program

The program automatically calculates each student's average grade and even converts it to a letter grade (A, B, C, D, F). It can handle up to 10 students with 10 grades each.
